Fullstack & Mobile Developer

Energy start-up: real-time collective solar self-consumption. Sween shut down in 2025; its codebase was acquired by Sunbiose, and the code I left there is still running.

  1. Joined at iteration zero of a real-time collective self-consumption energy platform, where metering data drives member billing: data reliability and consistency were non-negotiable.
  2. Built the cross-platform mobile app (Flutter) and web interfaces (React, Vue.js) for real-time monitoring of electricity production and consumption.
  3. Helped design and build the REST API serving both the mobile and web clients.
  4. Integrated Linky smart-meter data, so monitoring and billing run on actual readings.
  5. Took part in design choices and in running the infrastructure: Kubernetes, Redis and PostgreSQL, self-hosted across multiple OVH zones.
  6. Built two products from scratch: an energy community management tool and an interactive self-consumption simulator.
